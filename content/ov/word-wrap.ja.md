`ov`は行の折り返しモードを切り替えられます。
デフォルトは文字単位の折り返し（`-w` / `-w=char`）で、画面端で単語の途中が分割される場合があります。

## 折り返しモード

![文字単位の折り返し](/ov/ov-nowordwrap.png)

* `-w` または `-w=char`: 画面幅で折り返す（文字単位）。
* `-w=word`: 単語境界で折り返す。
* `-w=none`: 折り返しを無効化する。

```console
ov -w=word README.md
```

## ワードラップ

ワードラップを有効にすると、長文でも単語の途中で分割されにくくなります。

![word wrap](/ov/ov-wordwrap2.png)

起動後はデフォルトキー`Alt+w`でワードラップを切り替えできます。

## ワードラップ時のインデント

v0.55.0から、`-w=word`モードで折り返された行のインデントを`--break-indent`で指定できます。
起動後はデフォルトキー`Ctrl+Alt+n`でも設定できます。

### ワードラップ時のインデントの種類

#### `0`: インデントなし（デフォルト）

![インデントなし](/ov/ov-wordwrap2.png)

#### 正の数: 指定した幅でインデント

2を指定

![正の数](/ov/indent2.png)

#### `L`: 元の行の先頭の空白に合わせる

L(L+0)を指定

![元の行の先頭の空白に合わせる](/ov/indent+0.png)

#### `L+N` / `L-N`: 元の行の先頭の空白を基準に幅を増減する

L+2を指定。先頭のLは省略可能です。L+2は+2と同じ意味です。

![元の行の先頭の空白を基準に幅を増減する](/ov/indent+2.png)

```console
ov -w=word --break-indent=L+2 README.md
```

## display markers

v0.55.0から、折り返し位置や行の続き、画面幅による切り詰めを示すマーカーを表示できます。
`--sign-mode`で設定し、起動後はデフォルトキー`Ctrl+Alt+m`で切り替えられます。
デフォルトの`0`ではマーカーを表示しません。値はマーカーごとのビット値を加算して指定します。

![display markers1](/ov/ov-marker1.png)

![display markers2](/ov/ov-marker2.png)

| 値 | 表示するマーカー | 表示条件 |
| --- | --- | --- |
| `1` | `↳` | 折り返された行の先頭 |
| `2` | `↵` | 折り返し前の行末 |
| `4` | `…` | 折り返しなしで画面幅を超えた行末 |
| `3` | `↳`と`↵` | `1`と`2`を併用 |
| `5` | `↳`と`…` | `1`と`4`を併用 |
| `6` | `↵`と`…` | `2`と`4`を併用 |
| `7` | すべて | `1`、`2`、`4`を併用 |

`↳`と`↵`は折り返しが有効なとき、`…`は折り返しが無効で行が画面幅を超えたときに表示されます。

```console
ov -w=word --sign-mode=3 README.md
```
